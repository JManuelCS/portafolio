# Portafolio de Manuel Camarillo

Sitio web personal en HTML, CSS y JavaScript. Diseño adaptable, animaciones sutiles y presentación de CajaGo y NFC Authenticity.

## Vista local

Abre `index.html` en el navegador o utiliza la extensión Live Server de Visual Studio Code.

## Publicar en GitHub Pages

1. Crea un repositorio público llamado `JManuelCS.github.io`.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. En Settings → Pages, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
4. Cuando GitHub complete la publicación, visita `https://jmanuelcs.github.io/`.

## Personalización

- Correo: cambia el enlace `mailto:` en `index.html` si prefieres otra dirección.
- Proyectos: actualiza textos y enlaces en la sección `#proyectos`.
- Colores: modifica las variables CSS en `:root`.
- Las visualizaciones de proyectos son ilustraciones hechas con HTML y CSS, no capturas reales. Puedes reemplazarlas por imágenes propias cuando quieras.

El código fuente de CajaGo no se incluye en este repositorio.
