# Portafolio MC — edición final

Portafolio personal de Manuel Camarillo, listo para GitHub Pages en `https://jmanuelcs.github.io/portafolio/`.

## Incluye
- Identidad MC original y animación binaria optimizada.
- Proyectos CajaGo y NFC Authenticity con imágenes locales, sin publicar código privado.
- Sección de tecnologías, contacto directo por Discord, correo y GitHub.
- Diseño adaptable, navegación por teclado, acceso directo al contenido, respeto al movimiento reducido y metadatos para buscadores.
- Sin dependencias de compilación: HTML, CSS y JavaScript.

## Publicar
Sube **el contenido** de esta carpeta (no la carpeta contenedora) a la raíz de tu repositorio `portafolio` en la rama `main`. En GitHub > Settings > Pages, configura `Deploy from a branch`, `main` y `/(root)`. Espera la publicación y abre la URL indicada.

## Contacto
El enlace de Discord abre un perfil de usuario. Según los ajustes del visitante y del propietario, puede requerir inicio de sesión o solicitud de amistad. El correo se conserva como alternativa.

## Nota
Las imágenes de CajaGo y NFC se incluyen como archivos de muestra de proyectos. No se publica su código fuente.
